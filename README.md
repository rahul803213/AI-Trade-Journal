# AI-Trade-Journal

An AI-powered trading journal that doesn't just track trades — it reviews them.
Instead of only showing win rates and charts, it reads your trades and surfaces
the behavioral patterns behind them: the mistakes you repeat, the setups that
actually work, the emotional exits you don't notice yourself making.

I'm a full-stack engineer building this **in public** to deepen my skills in
AI/LLM engineering on top of a Java + React stack. Follow the journey and the
lessons on [LinkedIn](https://www.linkedin.com/in/YOUR-HANDLE).

> 🚧 **Status:** Early development. Building it step by step, in the open.
> This README grows as the project does.

## Why I'm building this

I trade on the side, and I'm a better engineer than I was a trader — mostly
because I never reviewed myself. The tools I tried tracked *what* I did but never
told me *why* I kept doing it. So I'm building the tool I wanted: one that acts
less like a spreadsheet and more like a coach.

It's also a deliberately ambitious learning project — enough complexity to stretch
across the full stack and into applied AI.

## Tech Stack

**Backend**
- Java 17, Spring Boot
- Spring Data JPA / Hibernate
- PostgreSQL
- REST APIs

**Frontend**
- React, TypeScript
- Redux

**AI**
- LLM integration for trade tagging, review, and pattern detection

**Tooling**
- Maven, Git, Docker (planned)
